# 극축 정렬 분석 및 구현 계획

## 목표

N.I.N.A. 안에서 극 근처 촬영, RA 회전 전후 보정, 반복 촬영을 통한 고도/방위각 조정을 지원한다.
기존 TPPA와 비교할 핵심은 조정 단계의 갱신 속도와 별 추적 안정성이다.

## 근거와 현재 상태

- REA 공식 소스: https://github.com/morluto/rea
- 정적 .NET 분석 계약: https://github.com/morluto/rea/blob/main/docs/managed-code-analysis.md
- SharpCap 공개 동작 설명: https://docs.sharpcap.co.uk/4.1/9_PolarAlignment.htm
- N.I.N.A. 플러그인 템플릿: https://github.com/isbeorn/nina.plugin.template
- 로컬 N.I.N.A. 플러그인 프로젝트와 동일한 net8.0-windows / NINA.Plugin 3.2.0.9001로 시작한다.
- SharpCap의 실제 기능 어셈블리까지 추출하여 극축 정렬 상태 전환·해석 경로를 정적으로 확인했다. [후속 결과](sharpcap-polar-findings.md)를 참고한다.
- 자체 촬영·보정·조정 화면을 구현했다. 실제 장비 정확도 및 전체 갱신 속도는 검증 전이다.

## 조사 순서

1. 실제 SharpCap 어셈블리의 버전, SHA-256, CLR 메타데이터를 REA로 기록한다.
2. Polar/Alignment/PlateSolve 관련 타입을 찾고 정확한 타입 이름으로 범위를 좁힌다.
3. 상태 전환, 별 검출/매칭, 회전축 추정, 화면 좌표 변환의 호출 관계를 추적한다.
4. 네이티브 경계와 정적 분석에서 확인할 수 없는 동작을 따로 기록한다.
5. 공개 문서와 관측된 동작으로 요구사항을 정리하고 자체 C# 수학 및 영상 처리 코드를 작성한다.

## 구현 구조와 후속 작업

- Capture: N.I.N.A. 카메라/이미징 mediator를 통한 취소 가능한 촬영.
- Calibration: 초기 plate solve와 RA 회전 후 solve로 회전축 추정. 두 중심 좌표만으로 축이 유일하게 정해진다고 가정하지 않고 영상 자세/별 대응점과 충분한 회전량을 확인한다.
- Tracking: 빠른 별 정합 코어는 구현·합성 시험을 마쳤다. 현재 실제 촬영은 매번 N.I.N.A. solver를 사용하며 빠른 정합 연결은 후속 작업이다.
- Geometry: 단위 구면 벡터, 회전축, 천구의 극, 관측지 수평 좌표의 관계에서 각도 오차와 조정 방향을 계산한다.
- UI: 전체 오차, 고도/방위각 성분, 갱신 시각과 측정 경과 시간, 재보정 및 중지를 표시한다. 오래된 안내는 숨긴다.
- 검증: 합성 별 영상의 알려진 회전/이동, 남북반구, 자오선 및 각도 경계, 적은 회전량, 별 소실, 취소를 확인한다. 실제 장비 비교 전에는 정확도를 주장하지 않는다.

## 완료 기준

플러그인 빌드/로딩, 장비 없이 재생 가능한 영상 시험, 사용자 취소, 조정 방향 검증,
실제 장비에서 반복성과 갱신 시간 측정을 마친 뒤 배포 패키지를 준비한다.
