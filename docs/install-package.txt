Live Polar Alignment 0.1.0.90
Requires Windows x64 and N.I.N.A. 3.2.0.9001 or newer.

1. Extract the entire ZIP and close NINA.
2. Run Install-Plugin.ps1, or copy plugin contents into:
   %LOCALAPPDATA%/NINA/Plugins/3.0.0/Live Polar Alignment
3. Start NINA. Open PA Image and PA Controls using their single Imaging toolbar icon.
4. Connect the camera/mount and check the selected method.
   PoleMaster uses its stock-optics pattern. A main camera uses NINA's solvers.
5. Settings: Plugins > Installed > Live Polar Alignment > Options.
   Exposure is in milliseconds. Adjust gain in NINA Equipment.
6. Press Start. PoleMaster identifies Polaris automatically; click only if asked.
   Allow calibration and return to finish before using the adjustment bolts.
7. Move the selected star to the fixed target, then start fine monitoring.

General automatic RA defaults to 90 degrees. PoleMaster measures two 40-degree
intervals. Check cable clearance and direction. Home restart can move RA and Dec.

Field recording is optional, off by default and stored per NINA profile.
Records: %LOCALAPPDATA%/NINA/LivePolarAlignment/FieldSessions
Keep the whole session folder for offline review. No automatic upload.
Estimated image drift and independent drift verification are not user features.

The package does not alter NINA application DLLs or camera SDKs.
Stability measures repeatability; absolute equipment accuracy needs field validation.
Source: https://github.com/squallseo/Nina.LivePolarAlignment
